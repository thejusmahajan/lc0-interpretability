\chapter{Check Yourself}
\label{ch:check_yourself}

Do these exercises with a pocket calculator before checking the solutions below.

\section{Practice Exercises}

\begin{enumerate}[leftmargin=2em]
  \item At iteration 0, why do all four arrows have the exact same $Q$?
  \item \texttt{Kd6} returned an \textit{excellent} $+0.968$ and its score still fell from $1.763$ to $1.361$. Give both reasons.
  \item Compute $U(\text{Kf5})$ at iteration 2 from scratch.
  \item An arrow has $n = 3$, $W = 1.80$. A fourth evaluation returns $x_4 = 0.20$. Compute the new $Q$ both ways (direct and incremental).
  \item Which value does an unvisited arrow use --- the parent's or the child's? Why can it not be the child's?
  \item If the search runs 10,000 iterations and \texttt{Kd5} is visited 3 times, roughly how much does \texttt{Kd5} affect the root's final estimate?
  \item The FPU baseline fell from $0.75015$ to $0.66460$ even though no new bad news arrived. Why?
\end{enumerate}

\section{Solutions and Explanations}

\begin{enumerate}[leftmargin=2em]
  \item \textbf{Exercise 1}: None of them has been visited, so none has a measurement of its own. All four borrow the same parent value $0.97602$. Only $P$ distinguishes them, through $U$.
  \item \textbf{Exercise 2}: (a) $n$ went $0 \to 1$ so $U$ halved, $0.78752 \to 0.39376$. (b) $Q$ was replaced, the borrowed $0.97602$ giving way to the measured $0.96766$.
  \item \textbf{Exercise 3}: 
  \begin{equation*}
    1.745 \times 0.0538 \times \frac{\sqrt{2}}{1+0} = 1.745 \times 0.0538 \times 1.41421 = \mathbf{0.13279}
  \end{equation*}
  \item \textbf{Exercise 4}: Direct: $(1.80 + 0.20)/4 = \mathbf{0.500}$. Incremental: $Q_{\text{old}} = 1.80/3 = 0.600$, then:
  \begin{equation*}
    0.600 + \frac{0.20 - 0.600}{4} = 0.600 - 0.100 = \mathbf{0.500} \quad \text{(Identical)}
  \end{equation*}
  \item \textbf{Exercise 5}: The parent's, reduced by the FPU term. It cannot be the child's because the child position has not been created or evaluated --- there is nothing to read.
  \item \textbf{Exercise 6}: Almost nothing: 3 samples out of 10,000, about $0.03\%$ of the weight. This is Chapter~\ref{ch:three_questions} restated.
  \item \textbf{Exercise 7}: The \textit{visited policy mass} grew from $0.4513$ to $0.8936$ when \texttt{Kf6} was visited, so the reduction $0.33 \cdot \sqrt{\text{mass}}$ grew from $0.22169$ to $0.31195$. The engine gets more sceptical of untried moves as the explored share rises.
\end{enumerate}
