# Public-Domain Chess Library — the gold-tier source catalog

> Curated reference for the GM-annotation curriculum (`GM_CURRICULUM_PLAN.md`). These are world-class works
> whose **annotations we can legally ingest** as the gold `quality_tier`. **We build with what we already
> have for now** (user, 2026-07-28); this list is the shelf we draw from as we scale.

## The rule (be precise — copyright is the motto applied to sources)
- **US public domain = published 1930 or earlier** (95-years-from-publication; as of 1 Jan 2026, 1930 works
  entered PD). So **≤ 1930 = safe** in 2026; a 1931 work waits until 2027, etc.
- **Translations carry their OWN copyright.** A PD *original* (German/Russian) is free, but a modern
  third-party English translation is NOT. Use the PD original text + **our own machine translation** (the
  user confirmed language is no barrier), never someone else's in-copyright translation.
- **Verify the edition/first-publication year** before ingesting any specific PGN — reprints and revised
  editions can carry fresh copyright.

## ✅ Confirmed public domain (world-class — the gold shelf)
**Nimzowitsch** — *My System* (Mein System, 1925); *Chess Praxis* (1929). *(original German PD)*
**Capablanca** — *Chess Fundamentals* (1921); *My Chess Career* (1920).
**Lasker, Em.** — *Common Sense in Chess* (1896); *Lasker's Manual of Chess* (Lehrbuch, 1926, German).
**Réti** — *Modern Ideas in Chess* (1922); *Masters of the Chessboard* (Die Meister…, 1930, German).
**Tarrasch** — *Dreihundert Schachpartien* (1895); *Die moderne Schachpartie* (1912). *(The Game of Chess, 1931 — NOT yet)*
**Alekhine** — *My Best Games of Chess 1908–1923* (1927). *(the 1924–1937 vol., 1939 — NOT PD)*
**Znosko-Borovsky** — *The Middle Game in Chess* (1922). *(Art of Combination 1936 / Chess Endings 1940 — NOT PD)*
**Steinitz** — *The Modern Chess Instructor* (1889).
**Mason** — *The Art of Chess* (1895); *The Principles of Chess* (1894).
**Marshall** — *Marshall's Chess Swindles* (1914).
**Morphy (annotated by others)** — Löwenthal, *Morphy's Games of Chess* (1860); Sergeant, *Morphy's Games of Chess* (1916).
**Blackburne** — *Mr Blackburne's Games at Chess* (Graham, 1899).
**Bird** — *Chess History and Reminiscences* (1893).
**Tournament books** — *St Petersburg 1909*, *London 1922* (1923), *New York 1924* (Alekhine, 1925). *(Nottingham 1936 — NOT PD)*

## ⛔ Named but NOT public domain — EXCLUDE (honest correction)
Several you listed are still in copyright and must not enter, per our own quality/licensing policy:
- **Isaac Lipnitsky — *Questions of Modern Chess Theory* (1956)** — copyrighted. EXCLUDE.
- **Irving Chernev — ALL works** (1937–1978: *Logical Chess Move by Move* 1957, *Most Instructive Games* 1965,
  *Capablanca's Best Chess Endings* 1978, etc.) — copyrighted. EXCLUDE.
- **Later Znosko-Borovsky** (1936, 1940 titles) — copyrighted.
- **Most "Soviet school" collections** (Bronstein *Zurich 1953* [1956], Kotov, Botvinnik's annotated
  volumes, etc., published 1940s–80s) — copyrighted. A handful of pre-1931 Russian works qualify; the
  celebrated post-war Soviet canon does not (yet).
These are the future "extract-from-a-book" tier — legitimate only via licensing, never scraping.

## Finding the actual annotated PGNs (a future worker task)
Many of the ✅ works above have been transcribed to **annotated PGN** (original prose in `{comments}`) by
hobbyists/archives — the `great_masters.pgn` sample already found is one. Candidate hunting grounds:
Project Gutenberg, open GitHub PGN repositories, pgnmentor, chessgames.com. When we scale, a worker locates
these, **verifies the annotations against the PD original**, and tags them gold. Not now — we build with the
material in hand.
